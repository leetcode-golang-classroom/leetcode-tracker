# [0013] 3Sum

- 難度：medium　主題：`two-pointers`
- 題目連結：https://leetcode.com/problems/3sum/

## 題目說明

給定整數陣列 nums，回傳所有滿足 i、j、k 互不相同且 nums[i] + nums[j] + nums[k] == 0 的三元組 [nums[i], nums[j], nums[k]]。答案中不可包含重複的三元組。為了讓測試可比對，回傳結果中每個三元組內部由小到大排序，且三元組之間依字典序由小到大排序。

## 函式簽名

| 參數 | 型別 |
| --- | --- |
| `nums` | `int[]` |

回傳：`int[][]`

## 限制

- 3 <= nums.length <= 3000
- -10^5 <= nums[i] <= 10^5

## 範例測資

| # | input | expected |
| --- | --- | --- |
| 1 | `{"nums": [-1, 0, 1, 2, -1, -4]}` | `[[-1, -1, 2], [-1, 0, 1]]` |
| 2 | `{"nums": [0, 1, 1]}` | `[]` |
| 3 | `{"nums": [0, 0, 0]}` | `[[0, 0, 0]]` |
| 4 | `{"nums": [0, 0, 0, 0]}` | `[[0, 0, 0]]` |

完整測資見 `testcases/0013-3sum.json`（各語言 runner 共用，`input` 的 key 順序須與參數順序一致）。
