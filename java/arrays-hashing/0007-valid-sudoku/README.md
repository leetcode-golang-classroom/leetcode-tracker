# [0007] Valid Sudoku

- 難度：medium　主題：`arrays-hashing`
- 題目連結：https://leetcode.com/problems/valid-sudoku/

## 題目說明

判斷 9x9 數獨盤面目前已填入的格子是否有效：每一列、每一行、每個 3x3 方塊內，1-9 都不可重複。空格以 "." 表示，盤面不一定有解。

## 函式簽名

| 參數 | 型別 |
| --- | --- |
| `board` | `string[][]` |

回傳：`bool`

## 限制

- board.length == 9，board[i].length == 9
- board[i][j] 是 "1"-"9" 或 "."
